# Contributing

Thanks for helping improve Reficus.

- **Bugs and ideas:** [open an issue](https://github.com/81zi/reficus/issues/new/choose).
  If you have a fix in mind, describe it or paste a diff in the issue.
- **Pull requests** are limited to collaborators. Proposed changes are
  discussed in issues and implemented by the maintainer.
- **Security issues:** report them privately through
  [security advisories](https://github.com/81zi/reficus/security/advisories/new),
  not in a public issue.

Reficus uses only the Python standard library. Tests:

```bash
python3 -m unittest discover -s tests
```
